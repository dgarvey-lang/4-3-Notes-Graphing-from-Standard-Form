# 4-3 Notes Graphing from Standard Form

An interactive, step-by-step lesson on graphing y = ax² + bx + c: find the vertex with x = −b/(2a), plug in to find y, rewrite in vertex form, and graph with the pattern.

**Student link:** https://dgarvey-lang.github.io/4-3-Notes-Graphing-from-Standard-Form/

You can also open `4-3 Notes Graphing from Standard Form.html` directly in a browser.

Steps:
1. Standard form (find a, b, c)
2. Finding the vertex x: x = −b/(2a)
3. Finding the vertex y and writing vertex form
4. c is the y-intercept
5. How to graph from standard form
6. Example: y = x² + 10x + 22
7. Practice: graph 3 equations
8. Notes checklist
